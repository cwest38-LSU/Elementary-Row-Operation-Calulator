Does Elementary row operations, the user needs to type in the CSV themself, the program will auto read it and make a matrix based off of that.
Use the first line of the CSV to label the number of rows then number of columns (otherwise it gets hairy) and can then populate the lines under with the integers used in the matrix.
Separate entries by commas in the CSV DO NOT TYPE SPACES or it will bust.
Use the numbers delineated in the "What operation..." box to choose which operation to do.
For example, to add first type 1 and press ENTER, then type what number to multiply the first row by and press ENTER, then type the first row number and press ENTER, then the second row number and press ENTER and it'll print out again.
